# Magic Tools (awesome-list)

Upstream: [ellisonleao/magictools](https://github.com/ellisonleao/magictools)

A curated list of game development resources (assets, engines, audio, learning, communities).

## How to use in this repo

1. Prefer **local Chromaracers pipelines first** (Three.js race, SpriteCook skills, Godot when scaffolded, CCGS `ccgs-*` process skills).
2. When the user needs external tools/assets, open the live list:
   - Raw README: https://raw.githubusercontent.com/ellisonleao/magictools/master/README.md
   - Repo: https://github.com/ellisonleao/magictools
3. A snapshot mirror for offline browsing lives at `docs/references/magictools-README.md` (may lag upstream).
4. Do not bulk-download random assets into the repo without an explicit request and license check.

## Sections that matter most for Chromaracers

- **Graphics → Assets/Placeholders** — OpenGameArt, Kenney, Quaternius, etc.
- **Graphics → Spritesheet Tools / Animation**
- **Code → Engines and Frameworks** — Three.js, Babylon.js, Godot, …
- **Audio → Collections**
- **Learn** — tutorials and books
