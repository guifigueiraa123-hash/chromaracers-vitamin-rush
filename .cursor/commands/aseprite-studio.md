# Aseprite studio (Chromaracers)

Run the Aseprite AI Artist **studio** workflow for this repo.

1. Ensure MCP server `aseprite-ai-artist` is available (see `.cursor/mcp.json`).
2. Call `preflight`. If not ready, stop — do not edit files on disk.
3. Follow MCP prompt / resource `aseprite:studio` (or `skill://studio`).
4. Export finished art into `assets/` for the Three.js race.
5. Map subjects using `docs/references/aseprite-ai-artist.md`.
